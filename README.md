# 🏭 SmartMine Safety Agent (智慧矿山安全合规诊断智能体)

> 本项目是一个基于大语言模型 (LLM) 和多智能体 (Multi-Agent) 协同架构的概念验证 (POC) 系统，旨在解决复杂工业现场（如矿山）安全排查高度依赖人工经验、合规审查效率低下的行业痛点。

## 🎯 项目愿景：回归安全管理的第一性原理

在构建智慧矿山的信息化规划中，我们发现传统的安全管理往往流于形式，现场隐患与安全规程之间存在巨大的“信息鸿沟”。本系统的设计初衷回归安全管理的核心——**从现场物理实体的真实反馈出发，直接映射至最底层的安全法规。** 通过打通“现场数据提取 -> 法规知识检索 -> 专家逻辑决策”的链路，系统致力于实现安全管理的**知行合一**：不仅“知”（精准检索法规），更要“行”（输出可直接落地的停机、排查等闭环执行指令）。

## 💡 核心痛点与解决方案

### 传统痛点
* **合规门槛高**：安全生产法及各类行业规程繁杂，一线运维人员难以在紧急工况下迅速背诵并对应具体条款。
* **经验依赖重**：对设备异常（如温度升高、异响）的严重程度判断，极度依赖老专家的个人经验。
* **响应链路长**：从发现隐患到出具标准化的安全整改报告，往往需要数小时甚至数天。

### Agent 解决方案
系统采用三层 Agent 架构，将非结构化的现场口语汇报/巡检日志，自动转化为结构化、合规的极速诊断报告。

## ⚙️ 核心逻辑流 (Workflow)

本项目核心包含三个协同工作的 Agent，并引入了思维链 (Chain of Thought, CoT) 推理：

1. **🕵️ Data Analyzer Agent (现场数据分析)**
   * **输入**：自然语言描述的巡检日志或语音转写文本。
   * **动作**：通过实体识别，锁定目标设备（如：带式输送机），并提取关键异常特征（如：防滑传感器离线、温度异常）。
2. **📚 Compliance Retriever Agent (合规审查与 RAG)**
   * **动作**：接收目标设备信息，调用内部规程知识库（模拟 RAG），精准锚定与该设备相关的强制性安全条款（如《安全规程》第三百七十三条）。
3. **🧠 Decision Maker Agent (专家决策与 CoT)**
   * **动作**：综合“现场异常现状”与“规程硬性要求”，触发思维链推理。评估风险等级，并生成包含明确违反条款和“闭环整改建议”的标准化诊断报告。
